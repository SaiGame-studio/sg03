# caveman

Model response compression to caveman prose (drops articles, pleasantries, hedging). Saves ~65-75% tokens.

## Commands
- `/caveman` (full mode, default)
- `/caveman lite` (lighter)
- `/caveman ultra` (bare fragments, abbreviations, arrows)
- `/caveman wenyan` (classical Chinese)
- `stop caveman` / `normal mode` (disable)

## Auto-clarity
Reverts to normal prose for safety warnings, destructive actions, and ambiguity.
