# Sai Game - SG03 (Dự án Game Unity)

Chào mừng bạn đến với kho lưu trữ mã nguồn dự án **SG03**. Đây là dự án game được phát triển trên nền tảng **Unity**, tập trung vào cơ chế game thẻ bài (card game) kết hợp các yếu tố chiến thuật.

## 📌 Tổng quan dự án
Dự án được xây dựng với kiến trúc hướng sự kiện, tối ưu hóa giao diện bằng **UI Toolkit** và hệ thống quản lý tài nguyên **Addressables**.
Các tính năng chính trong dự án bao gồm:
* **Hệ thống trận đấu (BattleState):** Xử lý trạng thái lượt chơi, các pha rút bài (Alpha Draw Phase) và cơ chế tấn công.
* **Quản lý thẻ bài (Card & CardHolder):** Định nghĩa thuộc tính, sinh và sắp xếp thẻ bài trực quan.
* **Hệ thống tương tác:** Kéo thả bài, chọn mục tiêu tấn công và tương tác vật lý/giao diện người dùng.
