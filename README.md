# Sai Game - SG03 (Unity Game Project)

This game project is developed with **Unity** and focuses on card-game mechanics combined with strategic gameplay elements.
Prototype Playable: https://play.unity.com/en/games/b8c87d36-f027-45d9-af5f-e8d94bae2b07/sg03

## 📌 How to clone the project

1. Create a studio and a game in Sai Server: https://server.saigame.studio/games/new
2. Go to **Clone Game** and select **sg03-ready** in **Clone From**.
3. Clone the game to copy the complete SG03 database into your game.
4. Open SG03 in Unity, enter the ID of the game you created, and you can play and customize its content as you wish.

# Sai Game - SG03 (Dự án Game Unity)

Đây là dự án game được phát triển trên nền tảng **Unity**, tập trung vào cơ chế game thẻ bài (card game) kết hợp các yếu tố chiến thuật.
Prototype Playable: https://play.unity.com/en/games/b8c87d36-f027-45d9-af5f-e8d94bae2b07/sg03

## 📌 Hướng dẫn cách clone dự án

1. Vào Sai Server tạo 1 studio và game: https://server.saigame.studio/games/new
2. Vào mục Clone Game - Clone From: chọn game sg03-ready
3. Tiến hành clone để có toàn bộ database của sg03 trong game của bạn.
4. Bật Unity sg03 lên điều game id mà bạn vừa tạo vào là có thể chơi được và tùy chỉnh content tùy ý bạn.
