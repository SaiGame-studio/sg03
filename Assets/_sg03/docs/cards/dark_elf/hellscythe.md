# Hellscythe (Tử Thần Chiêu Hồn)

- **Mã Thẻ Bài**: `hellscythe`
- **Loại Thẻ**: `character`
- **Chủng Tộc**: `dark_elf` / `undead` (Bóng Tối / Tử Thần)
